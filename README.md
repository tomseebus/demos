# PA Automations demo's

Demo-websites voor prospects, live op https://demo.perfectautomations.nl/<naam>/ (GitHub Pages).

Nieuwe demo: maak een map met een korte naam (kleine letters, streepjes), zet daar `index.html` en `images/` in
met relatieve paden, commit en push. Binnen een minuut staat hij op https://demo.perfectautomations.nl/<naam>/.

De hoofdpagina stuurt door naar perfectautomations.nl; demo's worden niet door Google geïndexeerd
(`robots.txt` en `noindex` in elke pagina).
